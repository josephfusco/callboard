WordPress plugin

Rehearsal tracks for a cast, on their phones.

Sets of audio served from your own WordPress site. A persistent player, offline saving, lock-screen controls, push notices, and Add to Home Screen on iPhone. No accounts.

Keeps playing

Playback continues across pages.

Moving between sets, locking the phone, or switching apps does not stop the player. Artwork and controls appear on the lock screen and in Control Center.

Offline

Tracks save for offline, per track or per set.

Each row shows its own progress and a mark when saved. Saved tracks play without a connection. Removing offline copies requires a second tap.

The player

The player.

Play and pause morph between shapes. The level bars follow the audio where the platform allows it. The scrubber knob moves with the fill. All motion stops under Reduce Motion.

Notices

Notices reach the cast's phones.

Opt-in Web Push. Publishing a set sends a notification. Sets → Notices sends a message with an optional link.

How it works

Sets are posts. Tracks are attachments.

01

Add a set

Upload audio to a set in the admin, drop a folder into uploads, or fetch a playlist with WP-CLI where yt-dlp exists.

02

Share one link

The home page lists every set. Nothing to sign up for.

03

Add to Home Screen

A one-time hint on iPhone. Installed, it opens full screen with its own icon and launch image.

04

Post notices

Sets → Notices. Everyone who opted in hears about it.

Install

Install

wp plugin install https://github.com/josephfusco/callboard/releases/latest/download/callboard.zip --activate
wp callboard fetch 'https://www.youtube.com/playlist?list=…' --name="Spring Show"

Or upload the zip under Plugins → Add New. Requires WordPress 6.5 and PHP 8.1. Fetching from YouTube needs yt-dlp and ffmpeg wherever WP-CLI runs.
